# 로또 번호 추첨

웹에서 동작하는 로또 번호 추첨 서비스입니다.

## 기능

- 본 번호 6개 + 보너스 번호 추첨
- 실제 추첨처럼 공이 순서대로 등장하며 번호 롤링
- 2026년 당첨 결과 사이드바 리스트 (동행복권 API)
- 현대카드 스타일 미니멀 디자인

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. **번호 추첨하기** 버튼을 눌러 추첨합니다.
3. (선택) 헤더 이미지를 위해 `shingeki.png` 파일을 같은 폴더에 넣을 수 있습니다.

## 기술

- HTML, CSS, JavaScript (프론트만)
- 동행복권 API (CORS 프록시 사용)
